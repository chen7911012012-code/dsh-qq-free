# QQ 官方机器人自由发言台

让 **QQ 开放平台的官方机器人**（AppID / AppSecret 那一套，不是 NapCat）不再只能被动等 @：它可以主动开口，内容由 DeepSeek 现写，也可以在网页里手动发、按间隔自动发。

## 它解决什么

官方机器人默认只能「被 @ → 回复」。这个插件补上另一半能力：

- **主动发言**：通过开放平台 `POST /v2/groups/{group_openid}/messages`（或 `/v2/users/{openid}/messages`）推送不依赖 `msg_id` 的主动消息，也就是不需要任何人 @ 它。
- **DeepSeek 写内容**：接当前 profile 的 DSH 模型服务（默认 `deepseek-account` / `deepseek-flash`），围绕你给的话题写一句像群友说的话；人设（system prompt）可改。
- **自动开口**：设定间隔、偏好话题、静默时段、每个会话的每日上限，到点由 DeepSeek 自己找话说；也可以「现在就来一句」。
- **问答库**：维护「问题 → 答案」，群友 @ 机器人提问时它先查库、命中就按库里的答案回，未命中再用 DeepSeek 正常回答。网页里也能查库、一键把答案发到 QQ。
- **网页控制台**：状态、凭据、人设、目标管理、发送、DeepSeek 生成、自动发言、问答库、发送记录，全部在 DSH 里点完，不用改配置文件。
- **自带 QQ AI 对话通道**：插件自己连 QQ 网关收发私聊 / 群 @ 消息，问答库优先、DeepSeek 兜底（与官方 QQ 插件二选一）。
- **给智能体的工具**：`qq_free_say` 主动发言，`qq_qa_lookup` 查问答库，`qq_qa_save` 记住一条问答；任何 DSH 会话（包括 QQ 里的对话）都能用。

## 安装后的位置

- 左侧栏出现「QQ 自由发言」入口，点开就是主面板。
- 设置页出现「QQ 自由发言」栏目，内容相同。
- 插件详情页的「打开面板」按钮也会跳到主面板。

## 第一次使用

1. 打开面板，在「连接与模型」里填 QQ 开放平台机器人的 **AppID / AppSecret**（也可以改用环境变量 `QQBOT_APPID`、`QQBOT_SECRET`），保存。
2. 在「会话目标」里点 **导入已知会话**：插件会读取官方 QQ 插件 `~/.dsh-qqbot/model-prefs.json` 里已经记录过的群 openid 并导入；也可以手动粘贴 `group_openid` / `user_openid`，加一个备注名。机器人被拉进新群、收到新群消息或入群申请时，也会自动加入目标列表（群名取不到时先用「QQ 群 后6位」）。
3. 在「发一条（自由发言）」里输入内容，点 **发送到 QQ**；可以在成员下拉里选一个群成员，消息会以真正的 @ 开头（Markdown 的 `<qqbot-at-user id="..." />`）。也可以直接从本地选择图片/表情包/视频/语音/文件（≤5MB），可选说明文字；或点 **DeepSeek 写一句** 让它先写，再改。
4. 想让它自己说话：打开「自动发言」，选目标、间隔和话题，保存。开启后从当前时刻开始计时，第一句在一个间隔之后（急的话点「现在就来一句」）；之后只要不在静默时段、没超每日上限，它就会按间隔自己发。

> 官方开放平台没有「列出我加入的群」接口，所以目标必须用 openid 记录；导入是为了省去手抄的麻烦。

每个会话的每日上限默认 4 条，填 `0` 表示不设插件侧限制（平台自身的配额仍然生效）。

## 问答库怎么工作

- 打开面板的「问答库」卡片：填问题、答案，可选关键词；支持编辑、删除，右侧显示命中次数。
- 匹配按四级规则从强到弱：问题原文相同 → 关键词全部出现 → 问题互相包含 → 字符二元组相似度（默认阈值 0.45）。阈值可用 `qaThreshold` 配置调整。
- 群内问答：群友 @ 机器人提问时，问答库会**实时注入智能体的系统提示**（最多 30 条，答案超长会截断），所以不依赖模型是否主动调用工具；问题与某条相近就直接用该条的答案回复，未命中再按 DeepSeek 常识回答。需要精确匹配时还有 `qq_qa_lookup` 工具兜底。用户说「记住：问题是…答案是…」时，智能体会调用 `qq_qa_save` 入库。
- 网页问答：输入问题后「查问答库」只查库；「问 DeepSeek」在未命中时回退到 DeepSeek 现答。结果可以「发送到 QQ」或「存进问答库」。
- 边界：官方是否下发全量群消息取决于机器人权限。本机实测所在群会收到 `GROUP_MESSAGE_CREATE`（普通群消息也能收到），但自带通道默认只在 `mentions.is_you` 为 true 时回复；「不 @ 也接话」需要额外开关，目前没有开启。

## 自带 QQ AI 对话通道（可选）

插件自己连官方网关，直接做私聊 / 群 @ 的 AI 回复：

- 收到 `C2C_MESSAGE_CREATE`（私聊）或群消息事件（本机实测为 `GROUP_MESSAGE_CREATE`，带 `mentions`，其中 `is_you: true` 表示 @ 了机器人）后，**先让模型判断这句话是不是提问**：是提问 → 强制 DeepSeek 准确回答；是闲聊 → 用面板里的「闲聊智能体人设」接话。两条路径都由 DeepSeek 生成。
- 群里只回复 **@ 机器人** 的消息；回答开头会用 Markdown 的 `<qqbot-at-user id="提问人 openid" />` 真正 @ 提问的人（纯文本 `<@openid>` 会被 QQ 原样显示，已废弃；Markdown 失败时降级成 `@昵称` 文字）。普通群消息即使收到了也不插嘴。
- 每个会话保留最近 12 轮上下文；回复走被动回复（`msg_id`），不占主动消息配额。
- 每次问答都会记录到面板的「QQ 对话记录」，并追加到工作区文件 `qq-replies.md`（相对 `process.cwd()`，可在面板改路径；写不进去时退回插件数据目录）。
- 自带自动重连（含 session resume）、消息去重、单会话串行处理与心跳。

启用步骤：

1. 在「插件」里停用官方 QQ 机器人插件（`@tencent-connect/dsh-qqbot`）。同一个 AppID 同时存在两个消息接收方会抢事件、造成漏回或重复回复。
2. 打开面板的「QQ AI 对话（自带通道）」，点「启用通道」，再点「确认启用」。
3. 状态变成「通道已连接」后，私聊机器人或在群里 @ 它即可。

取舍：自带通道只有聊天 + 问答库，不带 DSH 工具、文件、会话、审批等能力；需要这些能力时，继续用官方 QQ 插件，并保持本通道关闭。相关配置为 `chatEnabled`、`chatPersona`（提问人设）、`chatAgentPersona`（闲聊智能体人设）。

## 违禁词与处罚

面板「违禁词与处罚」里配置：

- 启用开关、违禁词列表（每行一个，按包含匹配，不区分大小写）
- 生效群列表（`group_openid`，每行一个；留空不检测）
- **违规几次后禁言**（0 = 不禁言）、禁言分钟数、**违规几次后踢出**（0 = 不踢）；两个次数都启用时踢出次数必须大于禁言次数

命中后的处理（只对普通成员，管理员/群主豁免）：

1. 没到禁言/踢出次数：撤回消息 + 在群里警告，并提示「再 N 次禁言 / 再 M 次移出群聊」
2. 达到禁言次数（未到踢出次数）：撤回 + 禁言配置的分钟数；再次违规继续禁言
3. 达到踢出次数：撤回 + 移出群聊，然后清零该成员违规次数

默认是「第 2 次禁言、第 3 次踢出」。**这两个次数只能在 DSH 面板和主网页设置**，分群网页只读展示（群设置页会显示「违规 N 次禁言 X 分钟，违规 M 次移出群聊」），分群网页接口不接受修改。

限制：撤回接口要求机器人在该群是管理员，且只能撤回 2 分钟内的消息；超时会记录日志但警告仍会发。

## 群板块（一次发多个群）

面板「群板块」可以把 1–3 个群组成一个板块。之后：

- 手动发送、DeepSeek 生成并发送、发送媒体、自动发言、远程发言网页，目标选「板块」就会一次发到板块里所有群
- 每个群分别计算主动消息配额；某个群失败不影响其它群（结果里逐个返回）

## 远程发言网页

面板「远程发言网页」会启动一个独立 HTTP 服务（默认 `0.0.0.0:8788`），手机/其他电脑浏览器打开后用 **token** 登录，即可使用完整控制台：

- **发送**：选群/私聊/板块，发文字（可 @ 群成员）、从本地选图片/表情包/视频/语音/文件、让 DeepSeek 写一句
- **自动**：开关、间隔、话题、现在就来一句
- **问答**：查看/添加/删除问答库
- **管理**：入群申请通过/拒绝/移除、禁言/解禁/踢人、违禁词与处罚、违规次数重置
- **设置**：AI 通道开关/人设/问答库开关、入群欢迎、会话目标增删、群板块增删、远程信息

启用步骤：勾选「启用远程网页」，端口默认 8788，保存/启动；token 留空会自动生成，也可点「重新生成 token」。面板会列出带 token 的访问地址（本机 + 局域网 IP）。

**地址固定（重启不变）**：外网访问只走 Tailscale Funnel 的 MagicDNS 固定域名（`https://<主机名>.<tailnet>.ts.net`）。面板「固定公网地址」会自动识别并写进配置，也可手动改；主网页和分群网页的链接、token、端口都持久化，DSH 重启不会改变。插件启动时会检查 `tailscale funnel status`，Funnel 没指向本机端口就自动执行 `tailscale funnel --bg <端口>` 补回来。cloudflared 临时隧道（`https://xxx.trycloudflare.com`）已停用：它每次重启都会换域名。分群网页链接一律用服务端算好的绝对地址，不会再出现相对路径 `/g/<token>` 打不开的情况。

**分群网页的 @ 成员**：分群网页「发言」卡片可以直接 @ 本群成员——下拉框列出机器人记录过的成员，发送时走官方 Markdown @，失败会自动降级成「@昵称」文字。**注意事项**：如果下拉框里没有要 @ 的成员，说明机器人还没记录到他，先在群里 @机器人 发送「获取信息」，再回到本页点「刷新成员」；群友在群里说过话后也会自动被记录。成员昵称会先清洗不可见字符再显示，列表与成员管理页统一做 HTML 转义。

**分群网页公告**：DSH 面板「分群网页公告」卡片、或主网页「设置 → 分群网页公告」都能发布，只显示在分群网页顶部，不会发到 QQ 群。不选群 = 所有分群网页；选中群则只对这几个群的分群网页生效。显示方式两种：「仅显示一次」——访客点「知道了」后，这台设备（localStorage）下次打开不再显示；「每次都显示」——直到停用或删除。公告可停用/启用/删除，操作会写运行日志。

**分群网页发送图片**：分群网页「发言」页可以从手机相册/电脑选图片（≤5MB，图片或表情包）直接发到本群，走 QQ 富媒体消息；可选一句说明文字，会单独再发一条，并带上当前「@ 群成员」选中的成员。没有发言权限或本群「全部屏蔽」时按钮禁用并提示原因。

**分群网页的群管功能需要申请（打开要申请，关闭立即生效）**：分群网页里改「功能开关（逐项）」「入群人机验证」「沉默低等级成员清理」「今日运势」「入群欢迎（从关到开）」「添加代管」属于打开功能，会生成一条申请（`state.groupChangeRequests`，同群同类型会覆盖旧申请，功能开关只记录要打开的项目 `unblock`）；而关闭这些功能、改欢迎文案、移除代管都直接生效，不需要审批。申请会显示在 DSH 面板和主网页的「分群网页申请」卡片里，点「同意」才写入配置并生效，点「拒绝」则丢弃；分群网页会显示「已提交申请，等待同意」。

安全提醒：

- 默认是**局域网使用**：监听 `0.0.0.0:8788`，同一 Wi-Fi 的设备用 `http://<这台电脑的局域网IP>:8788/?token=...` 访问；Windows 防火墙需放行入站 TCP 8788。
- 页面是 **HTTP 明文**，token 就是密码；**不要直接把 8788 端口转发/映射到公网**，否则 token 会裸奔。
- 外网访问统一走 **Tailscale Funnel**：主机执行一次 `tailscale funnel 8788`（插件启动时也会自动补），手机/外网用 `https://<主机名>.<tailnet>.ts.net/?token=...` 打开；加密、不用端口转发，地址跨重启固定。cloudflared 临时隧道、frp、ngrok 都不再使用（地址会变）。
- 换 token 后旧链接立即失效。

## 入群欢迎与群管理

- **入群欢迎**：通道收到 `GROUP_MEMBER_ADD` 时，按模板发送欢迎语。欢迎消息是**主动消息**，受平台频率/配额限制。**每个群独立**：面板「入群欢迎与群管理」、主网页「设置 → 入群欢迎」都可以逐群设置开关和文案，分群网页也能直接改本群的欢迎（无需审批）；没有单独设置过的群沿用全局默认（`welcomeEnabled` / `welcomeText` / `welcomeGroups`）。模板支持 `{member_openid}`、`{group_openid}` 占位符，数据存在 `state.groupWelcomes`。
- **入群审批**：机器人是群管理员时会收到 `GROUP_JOIN_REQUEST`，面板会列出申请；可「通过 / 拒绝」（拒绝可同时拉黑），也可以点「刷新入群申请」从平台拉取列表。**未同意的申请不会被自动删除**：只有成员真正入群（`GROUP_MEMBER_ADD`）或管理员执行通过/拒绝时才移除；面板每条还有「移除」可手动清理本地残留（不影响平台申请）。面板审批可以填「操作人」，群内命令会自动记录操作人，审批结果写入发送记录与 `lastApproval`。
- **群内申请通知与审批命令**：收到申请后，会把「头像（尽力获取，取不到就用链接）+ 昵称 + 申请时间 + 验证消息/问答答案」发到**申请人要加入的那个群**，并提示管理员回复「同意 昵称」/「拒绝 昵称」。头像用群聊富媒体上传后单独发一条图片消息，会多耗一条主动消息，可在面板用 `joinNoticeAvatar` 关掉。群里只有 `member_role` 为 admin / owner 的成员能用这条命令；处理结果用被动回复，不消耗主动消息配额。通知本身也是主动消息，受平台配额限制，可在面板关掉（`joinNoticeEnabled`）。
- **禁言 / 解除禁言**：面板填成员 `member_openid`，或在群里发「禁言 @某人 60」「解禁 @某人」；只认管理员/群主。最长 30 天（43200 分钟）。
- **踢人**：面板填成员 `member_openid`（点两次确认），或在群里发「踢人 @某人」。
- **关于 QQ 号 / QQ 等级**：官方机器人接口只返回 `member_openid`、昵称、头像、入群时间，不返回 QQ 号，也没有 QQ 等级字段；面板不能直接填 QQ 号，通知里也无法显示 QQ 号/等级。群内用 @ 成员的命令可以完全避开 openid。
- **权限**：审批、禁言、踢人都要求机器人是该群管理员，并且群主在群设置/管理端给机器人打开对应权限；接口返回 40103011 / 40103012 时会提示去开权限。
- 接口频率：审批约 60 QPM，禁言/踢人约 30 QPM，超限平台会报错。

## 屏蔽成员

面板「屏蔽成员」里选一个群，填成员 `member_openid`，添加后这个人在该群的消息会被**完全忽略**：不回复、不执行命令、不参与违禁词检测。可随时取消。远程网页「管理」页也有同样功能。

同一张卡片还有「屏蔽 @ 某人」：消息里只要 @ 到这个人，整条消息就被忽略（不管发送者是谁，也不会触发 AI 或命令）。

## 云端同步（WebDAV）

把插件源码打包成一个 JSON bundle 传到 WebDAV 网盘，方便在其他电脑用同一个网盘账号取回：

- 面板「云端同步（WebDAV）」填 WebDAV 文件夹地址、账号、密码（坚果云用「应用密码」，不是登录密码）
- 「测试连接」验证；「立即上传」手动同步；勾选「改动后自动上传」后源码文件变化约 3 秒自动上传
- 另一台电脑填同一个 WebDAV，点「从云端恢复」，文件写入插件目录后重启插件生效
- 密码保存在本机 `.dsh/qq-free/config.json`，请用 HTTPS WebDAV
- 只同步源码/文档，不同步 `.dsh` 里的配置、state、问答库

## @某人 获取信息

群里发送「@某人 获取信息」，机器人会回复：

- 该成员的 openid
- 入群时间

入群时间优先调用官方「获取群成员信息」接口的 `joined_at`；该接口目前是内邀能力，拿不到时用本地 `GROUP_MEMBER_ADD` 事件时间；都没有则显示未知。

## 入群人机验证

- 面板「入群人机验证」选择群并启用
- 新成员入群后，机器人 @ 他发送一张包含 6 位数字的验证码图片
- 新成员需在 2 分钟内 @机器人 回复图片中的验证码
- 回复正确：回复「验证成功」，通过
- **未验证前发任何非验证码消息**：立即撤回该消息并记一次失败（回复提醒「已撤回消息…」）；**失败 2 次后移出群聊**
- 验证码回复错误也算一次失败：先回复「验证失败 2 次，已将 … 移出群聊」，回复完成后再踢出
- 超时（默认 2 分钟）：自动移出群聊
- **群处于全体禁言时**：新成员入群先不验证、不发验证码，只提示「禁言结束后发送任意消息再进行验证」；禁言结束后他发的第一条消息会被立即撤回，并 @ 他发送验证码开始验证（之后规则同上，5 分钟有效）
- 只有该新成员本人的回复有效，其他人回复验证码无效

## 入群问答自动通过

- 每个群独立配置：开关、问题（仅展示给管理员看）、正确答案。可在 DSH 面板「入群欢迎与群管理」、主网页「设置 → 入群问答自动通过」、分群网页「群设置 → 入群问答自动通过（本群）」设置。
- 开启后，QQ 入群申请里的「验证消息」或问答列表中的答案与配置答案一致时，机器人直接调用审批接口同意该申请，不需要人工点通过；比较时忽略空格、大小写、全角半角。
- 答案不一致的申请照常记录并通知管理员人工处理；自动通过成功会写审批记录（操作人「自动验证」）和运行日志。
- 与权限规则一致：在分群网页「打开」自动通过需要申请，管理员在面板/主网页同意后生效；「关闭」立即生效。本群被「全部屏蔽」时不能打开。
- 群屏蔽了「入群申请处理」功能时不生效。

## 群管理快捷命令

- `@机器人 禁@某人`：禁言 60 分钟
- `@机器人 解@某人`：解除禁言
- `@机器人 飞@某人`：踢出群聊
- `@机器人 添加代管@某人`：只把该人加到当前群
- `@机器人 群信息`：查看群信息

仅主人、群主、群管理员、代管可用；代管只在被添加的群生效。

## 权限模型

- **主人**：面板设置 `ownerOpenid`，在任意群都拥有管理权限
- **群主 / 群管理员**：按事件里的 `member_role` 识别（owner / admin），默认有管理权限
- **代管**：面板或群里「添加代管 @某人」添加；可审批入群、禁言、踢人、获取群信息
- 普通成员执行管理命令会被明确拒绝，不会被当成管理员
- 「添加代管 / 取消代管」只有主人、群主、群管理员可以操作
- 「群信息 / 获取群信息」只有主人、群主、管理员、代管可以使用

## 配额与限制

- 主动消息受 QQ 开放平台自身的频率和配额限制，超限时平台会返回错误码，面板会把原始错误显示出来。插件另有一层「每个会话每日上限」（默认 4 条），可在设置里调整。
- 不启用自带通道时，插件只主动发送、不接管收消息；群里的 @ 回复由官方 QQ 插件（`@tencent-connect/dsh-qqbot`）处理，两者可以同时运行。
- 启用自带通道后，由本插件接收私聊 / 群 @ 消息；此时必须先停用官方 QQ 插件，否则两个连接会抢事件。自带通道只在 @ 时回复，普通群消息不插嘴。
- DeepSeek 调用走 profile 的 llm 服务；没有挂载可用模型路由时，生成类按钮会明确报错，而不是静默失败。

## 数据文件

默认在 `~/.dsh/qq-free/`（Harness 以 profile 启动且暴露 `DSH_PROFILE_DIR` 时，则用该 profile 下的 `.qq-free/`）：

| 文件 | 内容 |
|---|---|
| `config.json` | 面板保存的设置与凭据（仅本机，权限 0600） |
| `state.json` | 会话目标、发送日志（最近 200 条）、每日配额计数、上次自动发言时间 |
| `qa.json` | 问答库条目（问题、答案、关键词、命中次数） |

面板底部会显示实际使用的目录。日志与计数只影响本插件，删除这两个文件即恢复初始状态。

## 安全说明

- 面板路由与 DSH Web 同源，并以 `Origin` 做最小 CSRF 校验；本机回环地址可访问，因此**本机上任何程序**都能调用发送接口。不要把 DSH Web 暴露到不可信网络。
- AppSecret 保存在本机数据目录的 `config.json`，与 `cordis.patch.yml` 里的凭据同级；面板不会回显已保存的 secret。
