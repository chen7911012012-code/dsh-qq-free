dsh-qq-free

QQ 官方机器人自由发言台 · DSH 插件

开源 · MIT（附署名要求）

直接安装

从 GitHub Release 安装（推荐）：

npx @deepseek-ai/dsh plugin --profile <profile> add https://github.com/chen7911012012-code/dsh-qq-free/releases/latest/download/dsh-qq-free.tgz

或把下面的插件市场索引加到 DSH 的插件市场源，然后在「插件 → 发现」里搜索「QQ 自动发言」一键安装：

https://chen7911012012-code.github.io/dsh-qq-free/market/index.json
下载最新版 GitHub 仓库

功能

  • 主动发言：不必被 @，可发文字、图片/表情包/视频/语音/文件
  • 群 AI：先判断提问/闲聊；提问强制 DeepSeek，闲聊用智能体人设
  • 违禁词：撤回警告 → 禁言 → 踢出
  • 屏蔽成员：忽略某人的消息，或忽略「@ 了某人」的整条消息
  • 入群欢迎、入群审批（显示成员/群 openid）、禁言/踢人
  • 群板块：1–3 个群一次群发
  • 远程网页控制台（手机可用）
  • WebDAV 云端同步 + GitHub 自动同步
